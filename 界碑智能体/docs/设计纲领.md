# 友谊关 3D 研学探索 · 设计纲领

> 世界：`world.html`（真实扫場）· 服务：`python server.py` @ 127.0.0.1:8765
> 本文是玩法规划与标定依据；改动坐标前必读「坐标铁律」。

## 场景切换

- `world.html` = 友谊关关楼场景；`world.html?scene=post` = 边境哨所场景。
- **切换入口（三处）**：顶栏常驻按钮「前往边境哨所 / 返回友谊关」；研学卡「前往下一站」；哨所院内的返回路牌。
- **小地图**：顶栏「地图」开关；俯视渲染图（`assets/ui/*-minimap.png`，由 build 脚本 FLAT 正交渲染输出）+
  玩家蓝点实时定位 + 任务/巡逻点标注；映射参数在 `MAP_BOUNDS`（world.js）。
- **哨所夜巡模式**：顶栏「夜巡模式」——夜空+月光+沿路暖光池（PointLight）+门槛灯，`world.js` setNight 分支。
- 哨所北缘为**中越边境线**（红白画带+界桩排），线北为越南方向民居剪影与「越南方向」指示牌；
  营房门可进入（内景：双层床/书桌/储物柜），院内有巡逻脚印引导线。

## 整体关系与手册分家

- **三个页面**：`index.html` 行走的界碑（四朝代对话+TTS，整体 A）↔ `world.html`（友谊关）↔ `world.html?scene=post`（边境哨所），A/B 之间经顶栏「行走的界碑 / 3D」按钮互跳，B 内部两场景经顶栏/研学卡/返回路牌互跳。
- **爷爷实时对话**（`js/GrandpaChat.js`）：在爷爷面前按 E → 弹窗里点「🎤 和爷爷说话」或点问题快捷chip/打字 →
  录音上传 `/api/stt`（**本地 faster-whisper-small 离线识别**，模型在 `tools/whisper-model-small/`，
  经 `tools/build_post.py` 同款镜像下载；领域提示词+误听修正表见 server.py STT_FIXES）→
  `/api/chat`（Coze 按界碑爷爷人设+当前进度作答）→ `/api/tts`（与行走的界碑页同款 Fish Audio 音色）→
  播放 + 爷爷模型说话摆动动画。识别失败自动降级为打字；网络失败用本地关键词回复兜底。
- **手册与存档分家**：`QuestManager(ui, scene)` 按场景使用独立 sessionStorage（`friendship-pass-progress` / `post-patrol-progress`）；
  `UIManager.showHandbook` 按 `WORLD_SCENE` 渲染——友谊关=研学手册（3 证据+碎片/5），哨所=巡逻手册（POST_DISCOVERIES 6 项清单+碎片/6）。
- 哨所为巡逻玩法：6 处巡逻发现点（望远镜/对讲机/水壶/木箱/路线牌/边疆石碑），
  DiscoveryManager 计数 x/6，任务面板在哨所隐藏。
- 角色造型约定：**球体/胶囊重叠融合**的低模圆润风（build_student_v2 / build_grandpa_v2），
  不要再用离散方块拼接；新增角色沿用 `emit + sphere/capsule/tube` 管线。

## 一、核心体验（10–15 分钟自由探索）

核心问题：**为什么友谊关会建在这里？**

1. 出生台地远观关楼与山谷，产生好奇（开场只给问题，不剧透任务）。
2. 界碑爷爷在台地必经之处迎接，发布任务：找三个证据。
3. 玩家在三大区域自由寻找（非强制线性、无 Dashboard，3D 世界占主画面）：
   - **建筑**·关楼点（拱门前）→ 任务 A 观察城门洞/城墙/关楼（≥2 处）
   - **地形**·地形点（下山弯道俯瞰）→ 任务 B 选择题「山地通道」
   - **边界**·界碑点（关楼北侧谷底）→ 任务 C 辨认 中国/编号/年份
4. 集齐三证据回访爷爷 → 关键词组句 → **Coze 生成爷爷口吻点评**（失败降级为模板句）→ 生成《我的友谊关研学卡》。
5. 自由发现点（道路/石阶/城墙/导览牌/山间视线）贯穿全程，计入手册碎片。

## 二、坐标铁律（不许凭空猜）

- v2 世界坐标由 `build_world_v2.py` 的高度场定义，任务点可达性由脚本内 BFS（步高 +0.75/−1.2 每格）
  断言保证；碰撞体与地形同源，所见即所走。
- 坐标换算：**Blender (x, y, z_up) ↔ 页面 (x, −y, z)**；layout.json 中 `y` 是高度。
  旧扫描走廊工具 `plan_walkable.py` / `prepare_hunyuan_world.py` 仅服务 splat 回退线。
- 手工微调后用 Debug 面板（`world.html?debug`）「跳转到标定点 / 记录当前位置 / 设为XX点」
  校验，写入 layout 会经 `POST /api/layout` 落盘（版本号必须递增，浏览器草稿才不会覆盖）。
  注意：Debug 面板的保存会把**整份浏览器草稿**写回 layout.json——多端协作时以最新版本号为准。
- 当前标定：layout v8（v2 世界）：spawn (0,·,44) 街道南端 → 爷爷 (3,·,30) →
  关楼点 (0,·,6) → 界碑小院 (10.5,·,14) → 城墙步道地形点 (12.6,·,−3)；
  发现点：旗坊 (0,·,21)、石阶 (11.6,·,3.4)、城墙 (14.6,·,−5.4)、铁炮 (−6,·,5.6)、望北高台 (−14.4,·,−4.8)。
  改布局后：重跑 `build_world_v2.py`（看 V2_QUEST 全 OK）→ layout 版本号 +1。

## 三、资产管线（v2 设计态世界 · 现行）

**设计依据**：用户提供的友谊关实拍与概念参考图——灰岩城台 + 大拱门 +「友谊关」金字匾额 + 绿瓦多层楼阁 + 红旗；关前石板广场（石灯/旗坊/路牌/木箱）；两山夹峙、城墙顺山脊爬升、背景喀斯特青山；半写实卡通、儿童友好。

- `tools/build_world_v2.py` → `pass-v2-terrain/props/collider.glb`：**设计态高度场**（山脊夹峙中轴 + 关前广场大街 + 界碑小院 + 东西城墙步道），自带 **BFS 可达性校验**（新增任务点必须打印 V2_QUEST xxx OK，否则断言失败），碰撞体与可视地形**同源导出**（地形网格 + 城台阻挡盒 + 城垛护墙）。
- `tools/build_gate_v2.py` → `pass-v2-gate.glb`：城台（20m×8m）+ 圆拱门（净空 5×6m，沿 Y 轴）+ 金字匾额（simhei）+ 奶墙红柱绿瓦双层楼阁（顶约 20m）+ 红旗灯笼 + 古铁炮。
- 人物 1:1 真实比例（小孩 1.35m、爷爷 1.5m）对纪念碑尺度城台，比例关系对齐实拍照。
- 布景净空：广场/大街/小院/城墙步道沿线不撒树；旗帜/路灯/路牌/木箱沿中轴布置。
- 广场两侧四座边关民居（含碰撞盒）、界碑小院石桌石凳与门侧松柏均已进入 props/collider；

## 四、前端结构（js/，入口 world.js）

- `WorldManager`：Splat+Collider 加载、地面射线 `groundAt/placeOnGround`、移动碰撞 `movePlayer`。
- `CameraController`：第三人称；**焦点→机位遮挡检测**，被地形挡住时拉近（min 2.6m）并抬到坡顶 +0.9m；初始 yaw 1.16 / pitch 0.32 对准关楼。
- `NPCManager`：爷爷对话状态机（邀请 → 提示 → 终局点评）；`/api/chat` 25s 超时降级。
- `QuestManager`：not-started → active → return-to-npc → complete，sessionStorage 存档。
- `UIManager`：开场/对话/三任务观察流/证据卡/关键词总结/研学卡/手册。
- 模块走 import query 版本号（`?v=YYYYMMDD-xx`）防缓存；**改一个文件必须同步递增所有引用它的版本号**（含 world.html 入口）。

## 五、服务端（server.py）

- 静态 + `/api/layout`（GET/POST）+ `/api/tts`（Fish Audio 代理）+ `/api/chat`（Coze 代理，Redis 会话历史，`protocol=2` 兼容本机旧 Redis）。
- `/api/chat` 前端调用带 25s AbortController；`ok:false`/超时 → 前端用模板句兜底，绝不阻塞研学卡生成。

## 六、验收基准（每轮改动后跑一遍）

**改动任何 js/html/数据文件后必跑**：`node tests/check_frontend.mjs --api`
（语法 ESM 解析级检查〔含重复声明〕、import/资源引用存在性、数据与布局结构、
回归专项〔micButton 唯一声明、调试句柄不泄漏〕、API 冒烟；任一失败退出码 1。）

1. `world.html` 开场：中轴线正对关楼，旗坊/路灯/爷爷依次展开，无多余 E 提示。
2. 爷爷对话接任务 → 关楼点三处观察 → 城墙步道地形点（登城俯瞰）→ 界碑小院三处辨认。
3. 回访爷爷 → 关键词 → 研学卡「界碑爷爷说」出现 Coze 点评（server 日志有 `[chat] answer=…ch`）。
4. WASD 实走一遍中轴与登城石阶：上步 ≤0.65m 约束下全程可通行（BFS 已断言）。
5. 全程 FPS ≥ 110；相机不埋地、不穿模。

## 七、已知边界 / 后续

- toon 地形的零星尖柱是区域边界切在真实山脊上的峭壁，属低模风格的一部分；如碍眼可在
  `build_world_toon.py` 里对非走廊格加大平滑次数。
- 小地图、边境哨所（下一站）、经验体系为占位，待后续阶段。
- 关楼塔顶/石阶未纳入可达范围（真实台阶坡度超步高限制）；如需登塔需单独做楼梯碰撞引导。
