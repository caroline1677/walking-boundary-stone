# 友谊关界碑研学智能体

## 统一调用方式

前端只调用一个对话入口，由 Coze 根据自然语言识别意图并调度工具。当前项目通过本地后端代理调用 `stream_run`，API Token 只放在 `.env`，不得写入前端。

## 能力与适用场景

1. **历史讲解**：检索友谊关、雍鸡关、镇南关、镇南关大捷、冯子材、孙中山等资料，以界碑第一人称讲述；当前左侧朝代（汉代、明代、清代、当代）必须作为回答上下文。
2. **场景图片生成**：根据描述生成写实、油画、水墨、水彩、素描等友谊关或边关图片；返回 Markdown 图片和下载链接。
3. **动态视频生成**：生成 4–12 秒、约 720p 的城楼、夕阳、木棉花或哨所动态视频；返回 MP4 播放/下载链接。
4. **AI 语音讲解**：用指定男声或女声将历史讲解、导览词、研学开场白合成为 MP3；返回可播放链接。
5. **研学文档生成**：生成研学手册、教案、研究报告、旅游攻略等 PDF/DOCX 下载文件。
6. **教学 PPT 生成**：生成包含历史、时间线、地图、任务、讨论题和总结的 PPTX。
7. **3D 交互场景生成**：生成可在浏览器探索的 Three.js 友谊关城楼或戍边哨所场景，支持鼠标/键盘/移动端交互、红旗动画和巡逻兵动画。

## 组合调度示例

- “讲镇南关大捷并配图”：历史检索 → 场景图片 → 界碑讲解。
- “准备一套研学材料”：历史检索 → PDF 手册 + PPTX。
- “沉浸式体验友谊关”：3D 场景 + 图片 + 语音。

## 前端展示约定

- 文本回答显示在可滚动的连续对话框中，每轮按“用户问题 / 界碑回答”显示。
- `![说明](图片URL)` 渲染为图片。
- MP3 使用 `<audio controls>`，MP4 使用 `<video controls>`。
- PDF、DOCX、PPTX 显示为带下载按钮的文件链接。
- 页面左侧选择的朝代要随请求传给后端，后端在 Coze 提示中限定时代背景。
- 生成失败时显示面向用户的简短错误，不显示 Token、调试日志或内部工具名称。

## 验收标准

- 历史问题能返回界碑口吻的真实答案，并符合当前朝代。
- 图片、视频、音频、PDF/DOCX/PPTX 链接能在对话框中正确展示或下载。
- 连续两轮问题能保持 session 上下文；Redis 每个 session 最多保存 100 轮。
- 回答卡片不改变三列布局，桌面端左、中、右三列底边对齐。
- Coze 或工具失败时有用户可理解的回退提示，绝不泄露内部配置。
