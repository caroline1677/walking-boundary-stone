# 「一块行走的界碑」· 友谊关边关历史研学智能体

> 我是一块行走的界碑。我见证了雍鸡关、镇南关到友谊关的历史变迁。
> 你可以问我一段边关历史，也可以让我为你生成一份研学任务。

本项目是 **2026 年人工智能赋能教育创新应用大赛（桂教通平台赛道）** 的参赛作品，面向中小学生（用户单位：凭祥市第四小学），以友谊关（历史上先后称雍鸡关、镇南关、睦南关、友谊关）为研学对象，由 AI 扮演"一块行走的界碑"，第一人称讲述边关历史、设计研学任务、带领学生完成"观察—证据—推理—表达"的完整探究。

仓库包含三部分内容：

1. **桂教通平台智能体** —— 人设配置、自定义技能包 `youyi-guan-study-guide` 与全部参赛提交材料；
2. **本地 3D 研学演示**（`界碑智能体/`）—— 可独立运行的网页应用，含四朝代历史讲解、语音合成与真实扫描重建的 3D 边关漫游；
3. **素材与资料**（`友谊关材料/`、`_notice_pages/`）—— 实景照片、3D 扫描资产、大赛通知与评分点摘录。

## 核心特色

- **第一人称历史叙事**：以"界碑"视角讲解汉代雍鸡关、明代镇南关、清代镇南关大捷（冯子材）、当代友谊关四个时期，严格区分时代，不编造史料。
- **研学任务自动生成**：按时代、主题、年级、课时生成结构化的研学任务单（观察单、探究问题、课堂活动）。
- **学情记录与班级小结**：使用教师提供的匿名学生 ID 记录观察答案与提问，一键生成"数据概览—主要发现—教学建议"三段式学情报告。
- **时效信息查证**：开放时间、口岸动态等会变化的信息主动调用平台搜索并注明来源。
- **3D 边关漫游**：基于真实扫描资产重建的友谊关关楼与边境哨所两个场景，支持拖拽缩放、小地图定位、夜巡模式、研学任务与哨所巡逻玩法。
- **爷爷 NPC 实时语音对话**：录音 → 本地 faster-whisper 离线识别 → Coze 按人设作答 → Fish Audio 合成语音播放，各环节失败自动降级（打字输入 / 本地关键词兜底 / 浏览器语音）。

## 本地演示快速开始

### 方式一：直接浏览

双击 `界碑智能体/demo.html`（或展示包内的同名文件）即可查看演示；3D 漫游建议通过本地服务打开。

### 方式二：Python 本地服务（推荐）

```bash
cd 界碑智能体
pip install -r requirements.txt
python server.py
```

访问 <http://127.0.0.1:8765/>（首页）或 <http://127.0.0.1:8765/world.html>（3D 漫游）。

服务提供：

| 接口 | 说明 |
|---|---|
| 静态文件 | 网页与资源服务 |
| `GET /api/health` | 服务状态与 Fish Audio 配置检查 |
| `POST /api/tts` | 调用 Fish Audio 合成语音，结果缓存到 `assets/audio/cache/` |
| `POST /api/stt` | faster-whisper（small）本地离线语音识别，模型位于 `tools/whisper-model-small/` |
| `POST /api/chat` | 调用 Coze 完成爷爷 NPC 对话 |

### 方式三：Docker

```bash
cd 界碑智能体
docker compose up -d
```

容器只绑定宿主机回环地址（`127.0.0.1:8765`），公网流量请经 nginx 反代。

### 密钥配置

复制 `界碑智能体/.env.example` 为 `界碑智能体/.env`，填入自己的密钥：

```dotenv
FISH_API_KEY=          # Fish Audio，用于语音合成
COZE_API_TOKEN=        # Coze，用于爷爷 NPC 对话
COZE_BOT_ID=
```

未配置时功能自动降级：语音回退到浏览器 `speechSynthesis`，对话回退到前端内置内容，不影响浏览。**请勿把真实密钥提交到仓库。**

## 桂教通平台部署

1. 在桂教通智能体创作平台创建智能体，模型选择平台中文综合能力较强的通用模型（当前使用 Doubao-Seed-1.6）。
2. 上传技能包 `桂教通Skills智能体提交包/youyi-guan-study-guide.zip`，其中：
   - `SKILL.md` —— 能力路由与回答要求（历史讲解 / 研学任务生成 / 学情记录 / 时效信息搜索 / 配图要求）；
   - `references/history.md` —— 四朝代史料库；
   - `references/learning-records.md` —— 学情记录规范；
   - `scripts/generate-study-plan.mjs`、`scripts/summarize-learning-records.mjs` —— 任务单与学情小结生成脚本。
3. 按同一目录下的 `平台创建配置.md` 填写角色、人格、边界与开场白。
4. 完整提交流程见 `上传与提交清单.md` 与 `参赛材料准备清单.md`。

## 参赛文档再生成

`参赛DOCX/` 下的设计文档、验证报告、视频讲稿由脚本生成，修改内容后可重新生成：

```bash
pip install python-docx Pillow
python build_submission_docs.py
```

> 脚本内 `ROOT` 路径默认为本仓库根目录，若移动仓库请相应调整。

## 资产说明

- `友谊关材料/图片/` 中的 `.ply` / `.spz` 为友谊关关楼与边境哨所的高斯泼溅（Gaussian Splatting）3D 扫描资产，经 `界碑智能体/tools/` 下的构建脚本转换为网页可用的 `.glb` 场景。
- `tools/whisper-model*` 为本地语音识别模型权重（约 540MB），不入库；首次使用时由 faster-whisper 自动下载，或按 `docs/设计纲领.md` 的说明手动放置。

## 安全与隐私

- 所有密钥（Fish Audio、Coze、服务器 SSH 等）均通过本地 `.env` / 环境变量注入，已全部排除在版本控制之外。
- 学生数据只使用教师提供的匿名 ID，不收集身份证号、电话、地址等敏感个人信息。
- `新建文件夹/`（个人证书等私人材料）同样被排除，不入库。
