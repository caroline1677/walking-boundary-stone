# 学情记录字段约定

## 记录格式

仅接受教师提供的匿名学生ID，不收集身份证号、手机号、家庭住址或其他与研学无关的敏感信息。每条记录建议包含：

```json
{
  "studentId": "S-001",
  "era": "清代",
  "question": "冯子材是谁？",
  "observation": "从战斗群像中看到清军红色号衣",
  "understanding": "能说出1885年和镇南关大捷",
  "createdAt": "2026-08-28"
}
```

## 班级小结

对记录按 `era` 分组，用提问数量表示关注度，用观察和理解字段归纳学习表现。报告不评判学生优劣，不输出可识别单个学生的敏感描述，只给教师提供下一次研学的改进建议。
