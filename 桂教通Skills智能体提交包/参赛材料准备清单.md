# 「一块行走的界碑」参赛材料准备清单

## 三、智能体设计与开发文档

### （一）功能说明

需写清：

- 名称：「一块行走的界碑」友谊关边关历史研学 Skills 智能体。
- 定位：面向中小学生和带队教师的边关历史研学导师。
- 核心功能：四个时代的历史讲解、现场观察与动手研学任务、时效信息搜索核验、匿名学生学情记录与班级小结。
- 目标用户：凭祥市第四小学学生、研学教师、历史教师和学校研学活动组织者。
- 解决问题：把分散的友谊关史料转成分时代、有证据、可在现场执行的研学体验。

### （二）场景与工作流设计

文档中放一张流程图或以下文字流程：

```text
学生/教师提问
  → 判断时代、任务类型和是否需要配图
  → 读取友谊关研学知识库
  → 返回界碑第一人称历史讲解
  → 生成观察/动手/探究任务
  → 时效信息调用搜索工具并返回来源与日期
  → 教师提供匿名学生记录
  → 生成班级学情小结与下次教学建议
```

### （三）能力配置说明

需截图并说明用途：

| 能力 | 平台证据 | 服务的功能 |
|---|---|---|
| `youyi-guan-study-guide` 自定义 Skill | 技能列表截图 + ZIP | 历史讲解、研学任务、学情小结 |
| `generate-study-plan.mjs` | 代码截图 + 执行输出 | 按时代、年级、时长生成任务单 |
| `summarize-learning-records.mjs` | 代码截图 + 汇总输出 | 统计时代兴趣和教学建议 |
| Baidu Web Search / `websearch` | 技能或工具列表截图 | 搜索实景图片并注明来源 |

### （四）知识库/数据集说明

需写清来源、结构和调用方式：

- 来源：项目中的友谊关史料文案、现场图片和四个时代的编辑内容；外部实景图必须保留来源链接。
- 结构：按汉代、明代、清代、当代分组，包含时间、地点、人物、事件、证据和教学提示。
- 调用：历史问答和研学任务先按时代检索；学生记录只使用匿名ID，不收集身份证号、手机号等敏感信息。

## 四、应用验证与效果展示材料

### （一）演示视频（不超过5分钟）

建议录制以下节奏：

1. 0:00–0:30：展示智能体名称、人格和 Skills 列表。
2. 0:30–1:20：问汉代雍鸡关，展示时代锚点与配图。
3. 1:20–2:10：问1885年镇南关大捷，展示界碑口吻、时代锚点和实物证据。
4. 2:10–3:00：生成五年级、40分钟研学任务。
5. 3:00–3:45：记录匿名学生回答并生成班级学情小结。
6. 3:45–4:30：展示安全拒绝和历史纠错，余留时间展示分享链。

每条用例保留：用户提示词、系统提示词片段、任务流程、技能/工具调用、实际输出和通过判定。验收表覆盖历史讲解、研学任务、搜索核验、学生记录、学情小结、安全边界和历史纠错。
